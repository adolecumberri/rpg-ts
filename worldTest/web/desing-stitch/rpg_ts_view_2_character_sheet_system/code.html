1. CHARACTER SHEET ARCHITECTURE (320 X 640)

RATIO 1:2

The handheld profile view is strictly mapped to an 80×160 raster unit coordinate grid (1 unit = 4 physical pixels). The canvas divides vertically into 3 distinct functional zones designed for thumb accessibility and tactical readability:

ZONE A: STATUS HEADER 48 PX

12 units vertical. Houses the primary location badge, in-game calendar day, gold balance ledger, and save daemon validation flag.

`h-[48px] / bg-[#201010]`
ZONE B: SHEET CORE 400 PX

100 units vertical. Asymmetric split: dynamic animated combatant portrait left, combat attributes matrix right, and equipment hole registers.

`h-[400px] / bg-[#522929]`
ZONE C: ACTION TRAY 192 PX

48 units vertical. High-pressure 2×3 command matrix. Thumb-sized target buttons with tactile physical bevel depression states.

`h-[192px] / bg-[#1c0c0c]`

3. PRODUCTION CSS & BUTTON RECIPE

Handheld tactile depth is produced via micro-bevel shadows without using fuzzy standard drop-shadows. These are the copy-paste Tailwind tokens for the button bevels and card insets:
